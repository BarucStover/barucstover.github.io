MODEL DESCRIPTION

Mathematical Foundations

The system implements an all-to-all coupled Kuramoto oscillator model using a discrete Euler integration scheme.

Each oscillator has a natural frequency and an evolving phase. Coupling can produce collective synchronization, depending on the frequency distribution and initial conditions.

The displayed spatial network is an illustrative projection of oscillator phases. Its geometry does not represent physical interactions, molecular coordinates, or experimental measurements.

This demonstration is independent of ongoing experimental research and is not a validated biological or ferrofluid model.

Coupling Strength

Compare three coupling strengths using identical initial phases and natural frequencies. The experiment runs independently of the interactive visualization above.

Numerical experiment using forward Euler integration, 72 oscillators, σ = 0.7, α = 0, and Δt = 0.04. Synchronization time is defined as the first time R ≥ 0.9 remains sustained for five simulation-time units.

Time-Step Convergence

Test how the numerical integration step affects synchronization. Each simulation uses identical initial conditions and is compared against a finer reference calculation.

Forward Euler integration; 72 oscillators; sigma = 0.7; alpha = 0; simulation duration = 40. Reference step: 0.005. Errors compare R(t), not individual oscillator phases.

Euler vs. RK4

Compare first-order Euler integration with fourth-order Runge–Kutta using identical oscillator populations. Both methods are evaluated against a finer RK4 reference.

N = 72; sigma = 0.7; alpha = 0; duration = 40. Reference: RK4 with dt = 0.0025. Errors are calculated from synchronization R(t).

Perturbation Recovery

Compare how different coupling strengths respond to an identical phase disturbance after 20 simulation-time units.

RK4; N = 72; sigma = 0.7; alpha = 0; dt = 0.04. Perturbation at t = 20. Recovery requires maintaining at least 90% of pre-perturbation synchronization for 2 simulation-time units. Recovery is assessed only when pre-perturbation R is at least 0.9.

Disturbance Amplitude

Investigate how the magnitude of a phase disturbance affects synchronization recovery under different coupling strengths.

RK4; N = 72; sigma = 0.7; alpha = 0; dt = 0.04. Perturbation at t = 20. Recovery requires maintaining 90% of pre-disturbance coherence for 2 simulation-time units. Recovery is assessed only when the initial order parameter is at least 0.9.
